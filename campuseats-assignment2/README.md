## Contents

- **[design.pdf](design.pdf)** - Capabilities list, service contracts, placeOrder detailed specification, and service validation property table.
- **[services.drawio](services.drawio)** / **[services.png](services.png)** - Service architecture design mapping service boundaries, data ownership, and inter-service call operations.
- **[schema.drawio](schema.drawio)** / **[schema.png](schema.png)** - Database Entity Relationship Diagram (ERD) defining private schemas and cross-boundary references.
- **[schema.sql](schema.sql)** - Database table creation queries (DDL) grouped by service schema limits.

## Instructions
